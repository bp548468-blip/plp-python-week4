# PLP Python Week 4 - Functions Assignment

## Files
- welcome.py - A reusable welcome function that greets different users with Welcome to PLP message.
- toolbox.py - Contains three small functions: double, is_pass, and greet with optional greeting.

## Reflection
The hardest function was greet because it uses a default parameter and needs to join the greeting, comma, space, name and exclamation mark in the correct order.
